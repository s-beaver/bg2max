BG2MAX

Политика конфиденциальности

Редакция от 18 октября 2026 г. Действует для приложений BG2MAX (com.bg2max.app.reply) и BG2MAX Бот (com.bg2max.app).

Коротко. BG2MAX пересылает показания глюкозы из xDrip+ (и данные AndroidAPS, если он есть) в один чат мессенджера MAX, который вы выбрали сами.

Все данные хранятся только на вашем телефоне. Разработчик их не получает: в приложении нет аналитики, рекламы, учётных записей и своих серверов. Удалить всё можно кнопкой «Удалить все данные приложения» на главном экране.

Данные о глюкозе и инсулине — сведения о здоровье. Приложение обрабатывает их только для того, чтобы переслать их в чат, который выбрали вы. Если это данные другого человека, например ребёнка, нужно его согласие или согласие его законного представителя.

3. Кому передаются данные

  • Выбранному чату MAX. Сообщение с показанием видят все участники чата. BG2MAX отправляет его через приложение MAX на этом телефоне, от вашего аккаунта. У самого BG2MAX нет разрешения на доступ в интернет. BG2MAX Бот отправляет сообщение через MAX Bot API (platform-api2.max.ru). Как MAX обрабатывает сообщения, описано в его собственной политике конфиденциальности.
  • Тому, кому вы перешлёте журнал. Кнопка «Поделиться журналом» открывает стандартное окно Android «Поделиться». Журнал уходит только туда, куда вы его отправите сами.

Разработчику и другим третьим лицам данные не передаются. Приложение не показывает рекламу и не использует сторонние SDK для аналитики, рекламы или сбора сбоев.

4. Где и сколько хранятся данные

  • Всё хранится во внутренней памяти приложения на телефоне. Другие приложения к ней доступа не имеют.
  • Настройки и выбранный чат — пока вы их не удалите или не удалите приложение.
  • Последнее показание и последний пакет AndroidAPS — до прихода следующих: каждое новое значение заменяет предыдущее.
  • Журнал — не больше примерно 2 МБ. Когда он переполняется, старые записи удаляются. На экране видны 30 последних строк.
  • Копия журнала, созданная для отправки, лежит во временной папке приложения, которую Android может очистить сам.
  • Список чатов, из которых приходили уведомления MAX, хранится только в памяти до перезапуска приложения. Кнопка ответа выбранного чата хранится в тихом уведомлении «Связь с … сохранена», пока оно есть в шторке.

5. Как удалить данные

  1. Откройте BG2MAX и нажмите внизу главного экрана «Удалить все данные приложения». Трансляция остановится, будут удалены выбранный чат (или токен бота), настройки, журнал, последнее показание, данные AndroidAPS и уведомления приложения. После этого приложение откроется как после установки.
  2. Доступ к уведомлениям — настройка Android, а не данные приложения. Чтобы BG2MAX перестал видеть уведомления MAX, отключите его в Настройки → Уведомления → Доступ к уведомлениям.
  3. При удалении приложения Android стирает все его данные.

Сообщения, которые уже ушли в чат MAX, хранятся в MAX. Удалить их можно средствами MAX.

6. Разрешения приложения

  • Доступ к уведомлениям (BG2MAX) — найти уведомление выбранного чата MAX и ответить в него.
  • Получение данных xDrip+ — принимать показания глюкозы.
  • Уведомления и работа в фоне — постоянное уведомление о состоянии трансляции, работа при выключенном экране, запуск после перезагрузки.
  • Состояние сети — записать в журнал, была ли связь, когда показание не ушло.
  • Интернет — только у BG2MAX Бот, для отправки через MAX Bot API.

7. Дети

BG2MAX часто ставят на телефон ребёнка с диабетом, чтобы родители видели его показания. Устанавливает и настраивает приложение взрослый: он выбирает, в какой чат и каким людям уходят данные. Разработчик данные ребёнка не получает.
