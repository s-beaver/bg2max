# История версий

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация — [SemVer](https://semver.org/lang/ru/):
`MAJOR.MINOR.PATCH` — несовместимые изменения / новые возможности / исправления.

## [Не выпущено]

### Добавлено
- Приём broadcast'а AndroidAPS (`info.nightscout.androidaps.status`, модуль «Samsung Tizen»)
  с IOB/COB — пока только диагностика: последний пакет на главном экране, IOB/COB в журнале.
- Отказ от ответственности: показывается при первом запуске, без согласия приложение
  не открывается; доступен повторно с главного экрана.
- Лицензия GNU GPL v3.0, раздел о донатах в README.

## [1.1.0] — 2026-09-25

### Добавлено
- Дельта — изменение глюкозы с прошлого показания («Δ Изменение: +0.3 ммоль/л за 5 мин»).
  Включается галочкой в настройках. Не выводится для первого показания и если прошлое старше 15 минут.
- Номер версии в заголовке приложения и в журнале при запуске сервиса.
- Имя APK содержит версию: `bg2max-1.1.0-debug.apk`.

## [1.0.0] — 2026-09-13

Первая версия.

### Добавлено
- Foreground-сервис, принимающий локальный broadcast xDrip+ (`BgEstimate`) и пересылающий
  показания в MAX через Bot API: глюкоза в ммоль/л, стрелка тренда, время.
- Необязательные поля сообщения: скорость изменения, шум сигнала, батарея сенсора,
  источник данных, возраст сенсора.
- Отправка в личный чат или в группу; автоопределение Chat ID через `/updates`.
- Тестовое сообщение и симулятор показания без xDrip+.
- Инструкция в README и PDF-руководство для неподготовленного пользователя.

### Исправлено
- Доверие к корневому сертификату Russian Trusted Root CA для `platform-api2.max.ru`.
- Авторизация в MAX API только через заголовок `Authorization`.
