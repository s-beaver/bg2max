# История версий

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация — [SemVer](https://semver.org/lang/ru/):
`MAJOR.MINOR.PATCH` — несовместимые изменения / новые возможности / исправления.

## [Не выпущено]

### Изменено (главное)
- Основной вариант — бывший «BG2MAX Ответ» (`reply`), теперь он называется просто **BG2MAX**.
  Пакет `com.bg2max.app.reply` не менялся — обновление ставится поверх. APK: `bg2max-<версия>-debug.apk`.
- Вариант с ботом (`bot`) оставлен для экспериментов и называется **BG2MAX Бот**, APK `bg2max-bot-<версия>-debug.apk`.
- Инструкции: `bg2max-guide.pdf` — для основного BG2MAX, `bg2max-bot-guide.pdf` — для варианта с ботом.

### Добавлено
- BG2MAX Ответ 0.1.2: кнопка ответа переживает перезапуск приложения. Её копия хранится в тихом
  уведомлении «Связь с … сохранена», и после перезапуска отправка продолжается сама, без нового
  сообщения в чате. Не помогает после принудительной остановки приложения, если это уведомление
  смахнули или MAX отменил кнопку — тогда, как раньше, нужно новое сообщение из чата.
- BG2MAX Ответ 0.1.2: после перерыва от 3 пропущенных показаний в чат приходит подтверждение
  «✅ Передача возобновлена. Показания не приходили с 23:28 (пропущено 112).» — сразу, как только
  вернулась кнопка ответа, или первой строкой отложенного показания.
- Второй вариант приложения **BG2MAX Ответ** (`com.bg2max.app.reply`, версия 0.1.0, экспериментальный):
  отправка показаний кнопкой «Ответить» из уведомления MAX в выбранный чат, без бота, токена
  и разрешения на интернет. Защита от отправки в чужой чат, откладывание показания до появления
  кнопки, состояние в постоянном уведомлении, подробный журнал для проверки в реальных условиях.
- Полный журнал в файле (до ~2 МБ) в обоих вариантах.
- Приём broadcast'а AndroidAPS (`info.nightscout.androidaps.status`, модуль «Samsung Tizen»)
  с IOB/COB — пока только диагностика: последний пакет на главном экране, IOB/COB в журнале.
- Отказ от ответственности: показывается при первом запуске, без согласия приложение
  не открывается; доступен повторно с главного экрана.
- Лицензия GNU GPL v3.0, раздел о донатах в README.

- Строки из AndroidAPS в сообщении (каждая включается галочкой): активный инсулин (IOB),
  активные углеводы (COB), резервуар и батарея помпы, батарея телефона, профиль, последняя связь
  с помпой и последний болюс. Без AAPS или при данных старше 10 минут строки не добавляются —
  у пользователей только xDrip+ сообщение не меняется. Блок этих галочек в настройках виден,
  только если от AAPS хоть раз приходили данные; под ним — время последних данных от AAPS.

### Исправлено
- BG2MAX Ответ 0.1.1: уведомление выбранного чата, пришедшее на другой канал MAX
  (`ru.oneme.app.inapp.2` вместо `ru.oneme.app.chats`), отбрасывалось как «не наш чат» —
  теперь чат опознаётся по имени и постоянному id уведомления.
- В сообщении больше нет «Батарея сенсора: -1%» (xDrip+ не знает заряд) и «Сенсор: день 493»
  (устаревшая дата старта сенсора в xDrip+ при источнике «Other App»): такие значения не выводятся.
- Значок скорости при падении глюкозы — 📉 вместо 📈.

### Диагностика
- В журнал пишется причина, по которой система завершила прошлый процесс (Android 11+).
- BG2MAX Ответ: в журнал пишется, кто убрал уведомление выбранного чата из шторки.
- Одинаковые строки AAPS пишутся в журнал не чаще раза в 10 минут.

### Изменено
- Сборка разделена на варианты `bot` и `reply`; имена APK: `bg2max-bot-<версия>-debug.apk`,
  `bg2max-reply-<версия>-debug.apk`.

## [1.1.0] — 2026-09-25

### Добавлено
- Дельта — изменение глюкозы с прошлого показания («Δ Изменение: +0.3 ммоль/л за 5 мин»).
  Включается галочкой в настройках. Не выводится для первого показания и если прошлое старше 15 минут.
- Номер версии в заголовке приложения и в журнале при запуске сервиса.
- Имя APK содержит версию: `bg2max-1.1.0-debug.apk`.

## [1.0.0] — 2026-09-13

Первая версия.

### Добавлено
- Foreground-сервис, принимающий локальный broadcast xDrip+ (`BgEstimate`) и пересылающий
  показания в MAX через Bot API: глюкоза в ммоль/л, стрелка тренда, время.
- Необязательные поля сообщения: скорость изменения, шум сигнала, батарея сенсора,
  источник данных, возраст сенсора.
- Отправка в личный чат или в группу; автоопределение Chat ID через `/updates`.
- Тестовое сообщение и симулятор показания без xDrip+.
- Инструкция в README и PDF-руководство для неподготовленного пользователя.

### Исправлено
- Доверие к корневому сертификату Russian Trusted Root CA для `platform-api2.max.ru`.
- Авторизация в MAX API только через заголовок `Authorization`.
